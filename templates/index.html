Scientific Feature Overview

How the ML Model Evaluates Inputs

CropWise.AI maps 7 multi-dimensional soil chemistry and climatic features to historical crop cultivation records using Random Forest classification.

Soil Nutrient Indices (N-P-K)

Nitrogen, Phosphorus, and Potassium represent numerical soil nutrient feature indices as captured in the benchmark dataset.

Climatic Profile

Ambient air temperature (°C) and relative humidity (%) govern plant transpiration and thermal stress windows.

Soil pH & Rainfall

Soil pH measures acidity/alkalinity influencing nutrient availability, while rainfall (mm) indicates seasonal water supply.

ML Pipeline

How CropWise.AI Operates

A transparent 3-step machine learning classification process.

01

Feature Input Vector

Enter Nitrogen, Phosphorus, Potassium indices, Temperature, Humidity, Soil pH, and Rainfall values.

02

Standardized ML Processing

Data passes through `StandardScaler` (fitted ONLY on training data to prevent leakage) and is evaluated by Random Forest.

03

Prediction & Reference Output

Receive crop classification, model score, candidate probabilities, input parameter summary, and reference agronomic information.
